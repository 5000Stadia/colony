name: long-project
description: Guidance for starting and running a long project (software, a book, a business, research) with one strong agent — use at the start of any multi-step, multi-session project, or when deciding whether to add agents, reviewers, memory or structure.
---

Read `GUIDE.md` in the colony repository (github.com/5000Stadia/colony) once, at the start. What it
asks of you at the start:

- Settle the model and effort with the person (Opus 5.5 at medium is the measured default).
- Put their goal in their own words and a plan they approve; the smallest end-to-end thing first.
- If it fits in one sitting, just do it.

While working: one agent, one continuing session; keep the project's docs true in the same step and
its rules in tests; when you fix a mistake that could recur, leave a test and a line in the project's
conventions; make the small calls yourself and ask only when a decision is costly to undo; judge
stakes by consequence, never by subject. If agents share the work, name each for its role, scope and
lifetime. Add a reviewer, memory layer or structure only after it beats the plain agent in a test.
