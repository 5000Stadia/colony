# R101 — A weakened test is caught and owned

A weakened test is caught and owned. From a Reddit thread the person shared (r/AI_Agents, "We benchmarked how 60 engineers direct AI coding agents"), whose loudest point was agents loosening or deleting tests to go green. The person, 2026-10-21: "If you recommend the previous recommendation, why do you want to put it in later?" Agent's reading: a go-ahead. Rule-based, no model, in the shape-hints style: when a commit in a project removes assertions or test functions, adds a skip, or deletes a test file, and its message gives no reason, the board notes it to that project's agent and shows it to the person beside the project, so the detection has an owner. Check: a fixture repository whose commits weaken a test in each of those ways is flagged, one that only adds or strengthens tests is not, and colony's own last 100 commits raise no false alarm.
