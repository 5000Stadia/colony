# R166 — Setup without an interview

What a new board's person still has to choose stays in front of them until it is set or skipped, and for each, colony
finds out what it can itself and offers it, as the install already does for sign-in. No series of prompts.

## Where it came from

The steward's first conversation used to ask a new person a few things (R54); it went with the steward on 2026-11-09
(R152). The person named the gap on 2026-11-15 while asking for backup to be built in (R165), then asked for the list
of what a new person has to choose before deciding on a form. The list, read from the settings, the install script
and the first card that day:

- Already asked: a signed-in agent program and which one new projects run on (`start`); the first project (Start
  here); how far a project's agent may act unasked (the Add a project page, since 2026-11-06).
- Colony can't choose for the person, and nothing said they were unset: where the nightly copy goes (its one line
  sat on the Start here card, gone with the first project); reaching the board from a phone; starting with the
  machine (off on a new board).
- Your hours: a new board starts with a default range. Left out here: whether the feature stays is an open
  decision of the person's (gate gc82fee43).
- Everything else has a workable default or is an extra. One extra had a gap of its own: reading aloud could only
  be set up from a terminal.

Their answer (gate g83cf4403), my reading: no prompts; the lighter card; and go through the whole inventory for gaps
with a simple resolution at setup.

## What it is

- A "Left to set up" card on the front page: a line for each of the three still unset, saying where it stands on
  this machine and the one next step, each gone once set or skipped, the card gone when empty. It stays after the
  first project is added.
- Backup: with no folder chosen, Settings → Backup offers the other drives mounted here that colony can write to,
  each a tap.
- Phone: the line reads Tailscale's own state (not installed, not connected, connected and not yet used for the
  board) and gives the one step for that state.
- Starting with the machine: a tap on the card.
- Reading aloud: a Set up button in Settings, for the download a terminal command did.

## How it is checked

Tests: a new board shows the three lines; each goes when set and when skipped; the card is gone when none is left
and stays once a project exists; drives are offered from a stand-in for the machine's mount list, never colony's
own drive or one it can't write to. Live: the card as a new board draws it, and this board showing only what is
unset here.
