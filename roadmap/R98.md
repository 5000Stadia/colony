# R98 — The Library

The Library: one place in each project that takes any file or link, from the person or the agent, with the project's own documents found there by themselves; findable, searchable and opened from the phone. The person, 2026-10-20: "I also wonder if we should do a references and documentation element here as well as roadmap. Might be good especially for research snd such. Maybe links support this but maybe it should be more?", then "Just like roadmap i feel like reference, documents and library and the shape and value of it is specific per project but maybe not maybe just a shared dump that can take any file", then "Group headings would be nice for this as well probably initially organized by the initial shape from the agent but editable and organizable by the user and agent". Agent's reading: start as one place that takes anything (pins and the showcase already take uploads and links; the project's docs are indexed, not filed), grouped under headings the agent first sets from the project's shape and both of them can rename and reorder; the shape grows from what lands there (sources with what they support for research, drafts by chapter for a book, receipts feeding the money record for a venture), and evidence links tie a finding or item to its sources (shared with R97's findings view). Then, on pages: "the test benchmark that you put together for me that was quite a seamless switch in this interface to get to and run. Would that be a good artifact type that the agents could be informed of that might be stored in the library? ... We want to consider to give the agent in this space a malleable platform, to build items that can be shown to the user? Without having to create something separate or format in a particular acceptable format, like a PDF for the user to then have extra steps downloading", and "keep it elegantly in mind for the cohesive best form of library stuff". Agent's reading: pages are part of the Library: an HTML page an agent writes in the project opens from Chat or the Library as it is (sandboxed, scripts running); a page may send back what the person did on it, reaching the agent as a note from that page, never as their words; lasting pages stay in the Library, pages made for one decision are removed once it is made. Build order: the Library tab from what exists (documents, uploads, pins, showcase, pages), searchable on the phone; its headings, set first from the project's shape, editable by both; pages sending back; the index agents read at session start (blind-tested); one line telling agents (blind-tested).
