# R142 — Idle sessions hibernate

Idle sessions hibernate: a project's session idle a day, with nothing set to wake it, closes until the next word for it, then resumes in its own conversation. The person, 2026-11-01: "Can we have sessions that are inactive or 24 hours and have no timers to wake up go into like a hibernate state where the session actually closes until the next time the user sends a message or something triggers it to wake up?" Agent's reading: a console that has taken no turn for 24 hours, with no wake due, no helper or background command running, nothing typed in its box and no turn mid-way, is stopped (no process, no memory, no tokens), marked hibernating; anything that would reach it wakes it first and then delivers as today, resuming the same conversation: the person's message (board, console page), a note (theirs, colony's, an agent's), mail, a gate answer, a wake falling due, colony's notices (its carry-on nudge included, so a project with work it can start doesn't stay asleep). The cost to name: while asleep, the Claude and ChatGPT apps can't reach that project (its Remote Control goes with the session); the board always can, and its message wakes it. The installation's Codex repair connection is separate and stays up. Check: tests for each condition that keeps a session awake and each trigger that wakes one, resuming the same conversation; then live: a parked project hibernates after a day and a board message brings it back in its own conversation. Built and live 2026-11-01 (48c62a8). Then the person: "Colony could start in first load full hybernate except for projects last active in the 24 hours colony was last running". Agent's reading: when colony brings consoles back from cold (a reboot, or starting after being stopped), only projects that took a turn in the 24 hours before colony last ran (measured from when colony stopped, not from now, so a machine off a week doesn't put everything to sleep), or that something keeps awake (a wake set, a pause or limit waiting), come back running; the rest start asleep, recorded as hibernating, woken by their next word as any sleeper is.
