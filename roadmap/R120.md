Added 2026-10-28 from the Linux research (research library re1b5116b), asked by the person: "If you had to determine the best flavor of linux for colony to maximize performance and capability out of the box what would you pick". Verdict: stay on Ubuntu, with no switch. The gain any other distribution offers here is memory defaults, which Ubuntu gets with a setting. Every candidate runs the same scheduler, and nothing measured favours another for many mostly idle agents. Ubuntu 26.04 LTS is the Quickstart's target. For this machine, in order: (a) zswap on (`zswap.enabled=1 zswap.compressor=zstd` on the kernel command line; measured here: off, lzo), so what is swapped stays compressed in memory; (b) swap grown on the new SSD, as (1) says; (c) colony's part, measured here: every console runs in one tmux server, inside one GNOME Terminal scope, and user@1000.service has systemd-oomd set to kill at 50% memory pressure. One kill there would end every console at once, so the consoles need their own scope, or one oomd avoids, with Chrome and the voice limited first; (d) optional, upgrading to 26.04 right after the clone, the old disk the way back. Its cost: Python moves from 3.12 to 3.14, so every Python environment made on 3.12 is remade (colony's voice, projects' .venv folders).
