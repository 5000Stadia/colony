# R91 — Closing a project safely

Closing a project safely. The person, 2026-10-19: "Can a project close itself? Also if a project is closed and reopens does it continue the context history?", then "Can monitor handle safely closing projects?" and, to `colony close`, "Yes, please". Agent's reading: closing stays the person's call (a project's agent isn't taught to close itself); `colony remove` stopped a session at once, mid-step or with helpers running, and since R90 the monitor isn't woken when a turn ends, so it couldn't wait for a project to land its work. `colony close NAME` tells the agent to land its work (let running work and helpers finish, commit a clean point, start nothing new, say where things stand); once its note was handed over and its turn has ended with nothing running, the board takes it off, at no token cost, and the person hears of it with the monitor's news. Files and conversation stay, so `colony track` reopens it where it stopped; `--cancel` keeps it; delete only on the person's word. The monitor runs it when the person says close.
