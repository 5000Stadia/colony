# R104 — Lessons tied to the action they're for

Lessons tied to the action they're for. The steward counts the evidence colony keeps (a decline, a low rating, a gate answer that corrects, an item redone) and proposes a lesson, keyed to the action it is about (adding a connection, presenting a deliverable, asking a gate, building a page), for the person to adopt with a tap. An adopted lesson reaches an agent just as it takes that action, in three tiers: the project's own, the colony's (keyed to the action), and, on measured evidence only, GUIDE.md.
