# R134 — Pause a project, and resume it

Pause a project, and resume it. The person, 2026-10-31: "Id like an option to pause a project, which basically pauses the agents console. saves then retracts all gated needs you items. Unpausing Resurfaced those items then unpauses." Agent's reading: pausing stops colony from setting the agent going, and takes what it waits on off the person's list without losing any of it. If the agent is at work, it is told once to land what's in flight (helpers finish, a clean commit, nothing new), as a close or a safe pause does, so no work is lost. From then on colony types nothing of its own into its console: notes, mail, wakes, carry-on, recovery nudges and compaction all wait. Its gates, questions and items to verify leave Needs you, the counts and the steward's list; none is answered or withdrawn, and no skipped default stands while it is paused. The person's own messages in its Chat still reach it, since those are theirs to send, and anything it asks meanwhile waits with the rest. Resuming puts the held items back on the list as new, so a default stands a whole day after the resume, not from before the pause; then colony reaches the agent again: what queued is delivered, and if it was at work when paused, it is told to carry on. Where: Pause in the project's Settings beside Archive; while paused, a line on every tab of the project with Resume; its line in the sidebar says Paused; Needs you names the paused projects and how much each holds. The steward can do it for them: colony pause NAME (--off resumes). Check: tests that a paused project's items leave Needs you and the counts and come back on resume with the default's clock restarted; that no default stands while paused; that colony's own typing is refused and the person's goes through; that a working agent is told to land once; that resume tells it to carry on only if it was at work; and that items the person cleared stay cleared across a pause.
