# Pictures, files and links in the person's Chat

In the person's Chat, a picture in the project shows in your reply written `![what it shows](path)`, and a linked
file there (a PDF) opens; one made elsewhere is copied into the project first, and the copy linked. Link a project to
`/?n=NAME`, with its folder name URL-encoded (spaces as `%20`), so the link keeps its project as others are added.
