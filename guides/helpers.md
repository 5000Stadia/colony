# Working with helpers and other agents

Brief a helper with what it owns and where it ends; it reports as it goes rather than waiting. When work divides
cleanly, run helpers in parallel on separate files, review each result before it lands, and have each commit only its
own paths. Paired with another project's agent, keep to your agreed role and talk at hand-offs.

Helpers run at four tiers (routine, step-up, chores, rote), handed to you at each session start.
